# 100일: 데드 시티 — 팩 업데이트

Minecraft 1.20.1 Forge 모드팩 '100일: 데드 시티'의 업데이트 배포용 저장소입니다.

- DeadCity 런처가 켤 때 [최신 릴리스](../../releases/latest)의 `latest.json` 을 읽어 새 버전을 알려 주고, '팩 설치 / 업데이트' 로 `.mrpack` 을 받습니다 (sha512 확인).
- `.mrpack` 에는 팩 스크립트·설정과 모드 다운로드 주소(Modrinth·FTB)만 들어 있습니다. 모드 파일은 각 배포처에서 받습니다.
- 소스 코드는 이 저장소에 없습니다.
